# SeoBay India — Official Website Platform

Founder-led digital marketing and search visibility agency website for **SeoBay India**, directed by **Kapil Vashistha** (16 years SEO experience, Mansarovar, Jaipur, Rajasthan).

Built with **Next.js 14 App Router**, **TypeScript**, **Tailwind CSS**, and **Keystatic CMS**.

---

## Quick Start

```bash
# Install dependencies (if needed)
npm install

# Run local development server (Website at :3000, CMS Admin at :3000/keystatic)
npm run dev

# Run production build & verify 27 static routes
npm run build

# Start production server
npm run start
```

---

## Key URLs

- **Local Public Site:** `http://localhost:3000`
- **Visual Admin Panel:** `http://localhost:3000/keystatic`
- **Services Hub:** `/services`
- **Pricing:** `/pricing` (₹20,000/month baseline)
- **Jaipur Office:** `/locations/jaipur`
- **Master Experience:** `/experience`
- **Articles & Insights:** `/blog`
- **Consultation Funnel:** `/book-consultation`
